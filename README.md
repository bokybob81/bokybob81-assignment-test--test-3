# Student assignment submission template

Private submission repos are generated from this template by Simulation EG.

## Branch naming (required)

`assignment/{sectionOrder}-{assignmentOrder}`

Examples: `assignment/1-1`, `assignment/1-2`, `assignment/3-1`

## Folder layout

- `submission/assignment/` — your solution (required; at least one real file)
- `submission/leetcode/account.md` — only if the assignment requires LeetCode
- `submission/research/` — only if required
- `submission/book-reading/` — only if required
- `submission/linkedin/posts.md` — only if required (at least one https URL)

Open **one PR** from the required branch into `main`.
Keep this PR open; fix CI/platform feedback with new commits on the same branch.
